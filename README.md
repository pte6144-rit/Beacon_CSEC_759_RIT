# Easier BEACON: Making Directed Fuzzing Simpler

This is the repository for our (Group 3) final project for CSEC 759 Grad Seminar in Computing Security. 
This repository is a fork of the original BEACON repo. Our contributions are as follows:
- The LineNumber directory, which contains the C++ code for identifying the target lines, 
- The beacon.sh script, which automates and simplifies the compilation and instrumentations processes 
- The docker directory, which holds the dockerfile for the main image
- Software Security Report.pdf and .pptx, which hold our writeup and our presentation, respectively

Please refer to the powerpoint and pdf for further information. There is also more information about
how to use the script available with the docker image, search for patrickelser/beacon on docker hub
for this information or if you want to pull the docker image and run the container.
